# PUBG-Player-Performance-Analysis-EDA-Feature-Engineering-
Title:
PUBG Player Performance Analysis using Python

Description:
This project analyzes a large dataset of PUBG player statistics to identify the key behaviors that contribute to winning performance. The analysis includes data cleaning, feature engineering, and visualization to uncover meaningful insights about player strategies.

Key Tasks Performed:

Data quality assessment and cleaning of raw dataset
Handling missing values and outliers
Feature engineering to better represent player behavior
Exploratory Data Analysis (EDA) using visualizations

Engineered Features:

totalDistance = Total movement (walk + ride + swim)
headshotRate = Accuracy indicator (headshotKills / kills)
itemsUsed = Resource usage (heals + boosts)

Key Insights:

Players with balanced movement and combat tend to rank higher
Excessive passive play (high distance, low combat) reduces win rate
Aggressive players (high kills/damage) perform better up to a limit

Technologies Used:

Python
Pandas
Matplotlib / Seaborn
